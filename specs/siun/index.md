## 화면 명세 (옛 screen_spec)

**진입 조건:** 로그인 + 프로필 (비로그인은 CTA)

- `listProfiles` → is_self 우선, 프로필 전환 UI
- `getForecast(memberId, profileId, 31, today-14d)` → 과거 14일 + 미래 포함 31일 (백엔드 `days` 최대 35)
- 탭: 지난주 · 오늘 · 내일 · 모레 · 글피
- 지난주(R6): 지난 7일을 최근순으로 카드 나열. 각 카드 = 날짜·일진·점수 + `MorningBrief`(첫 "오늘"→"이날") + "맞았어요?" 👍/👎. 누르면 `POST …/feedback {tab_id:"daily:YYYY-MM-DD"}`, 진입 시 `GET …/feedback?prefix=daily:`로 이미 표시한 값 복원. 상단에 "표시한 N일 중 M일이 맞았어요"
- 일진 카드: 아침 한 마디·총점·레벨·일진 간지(한글 변환)·영역별 점수·팁·날씨 배지·절기·손없는 날. 아침 한 마디 아래 **한 줄**(2026-11-06 사용자): 네 칸 같은 꼴 "대운(10년) / 戊辰 무진 · 세운(올해) / 丙午 병오 · 월운(이달) / 己亥 기해 · 일진(오늘) / 甲申 갑신"(용어 10px + 쉬운 말 위, 간지 15px 오행 색 + 한글 읽기 아래, 용신 든 간지엔 금색 "용신" — 일진의 쉬운 말은 탭 이름 오늘·내일·모레·글피, 일진 글자만 `ink-stamp`), 세로선, 오른쪽에 종합 점수(19 2xl 위 · 종합 10px 아래, `score-pop`). 시간 단위가 10년 → 올해 → 이달 → 오늘로 좁혀지는 순서 — 옛 대운/세운/월운 3칸 그리드는 용어만 있어 일반 사용자가 몰라 2026-11-06 제거(작은 세 줄 안도 "조그만하게 적지 말고 나열"로 바뀜) — 간지 글자는 분석 사주팔자와 같은 `ink-stamp`로 한 자씩(0.25초 간격) 찍히고 점수는 뒤이어 `score-pop`, 날짜 탭을 바꾸면 다시 찍힌다. 좋은 날의 운수대통 직인(`LuckySeal`)은 점수 위에 그대로
- 오늘 탭 아래 "이 시간대가 좋아요"(오늘~글피 시간별 날씨 오행, 용신=최고·용신을 생함=좋음)·"주간 시운"(7일) 카드는 `components/SiunCards.tsx` — 홈(`specs/home` §3-1b)과 같은 컴포넌트(2026-10-26). 카드 제목은 카드 안 굵은 제목(카드 규약). 제목 줄 오른쪽 범례(최고=金 좋음=水)는 이 화면에만 — 홈 embedded는 2026-11-06 뺌
