## 1. 목적

옛 신문 별자리 운세의 문법(12별자리 + 오늘 한 줄)을 **오늘의 띠와 같은 모양**으로 홈에 둔다. 다른 데와 다른 점은 태양 별자리만 보지 않고 **출생 차트의 태양·달·상승**과 **오늘 하늘(달·태양)**의 관계로 문장을 고른다는 것 — 기본 프로필이 있으면 내 칸의 문장이 개인판이 된다.

지키는 원칙
- 문장·점수·레벨은 전부 백엔드(`horoscope_rules`). 프론트는 표시만, 레벨·점수로 문장을 고르지 않는다.
- 외부 기사·운세 API의 문장을 가져오지 않는다. 문장은 애스펙트의 전통 의미에 기대 우리가 쓴다(근거 `docs/research/home_홈화면.md` §7).
- 화면 폰트 서브셋 때문에 **응답에 한자·영문 없음**(별자리 이름·행운의 아이템·문장 모두 한글, 테스트가 검사).
- 출생 시간의 불확실함을 숨기지 않는다 — 모르면 상승 없음, 2시간 블록 안에서 바뀌면 "또는"으로 다 적는다.

## 2. 진입과 상태

| 상태 | 데이터 | 보이는 것 |
|---|---|---|
| 홈 로그인, 기본 프로필 있음 | `GET /members/{id}/home` → `me.horoscope`(개인판) + `today.sky`(일반판 12) | "나" 배지 · 내 태양 별자리 칸은 개인판 문장(백엔드 이름 접두는 홈에서 뗌, 2026-11-06), 다른 칸은 일반판. 출생 차트 칩 ☉☽↑은 2026-11-06 홈에서 뺌(설명 없인 낯섦 — `/stars` 내 별자리에 뜻과 함께) |
| 홈 로그인, 기본 프로필 없음 | 같은 응답의 `today.sky` | "나" 없음, 12칸 모두 일반판, 처음엔 오늘 달의 별자리가 골라짐 |
| 비로그인 | `GET /kkachi/today` → `sky` | 위와 같음 |

백엔드 호출은 홈이 원래 하던 1회 그대로(로그인 `/home`, 비로그인 `/kkachi/today`) — 별자리 때문에 요청이 늘지 않는다. 홈 카드 제목 줄 오른쪽 [자세히 →]로 `/stars`(별자리 상세 — 12별자리 전체·이번 주 달의 길·출생 차트 설명, `specs/stars/index.md`, 2026-11-06)에 간다. 홈 자체의 이벤트는 `home_view`만.

```
sky: {                                                  // 오늘 정오 KST의 하늘 — /kkachi/today 와 홈 today.sky 가 같은 값
  sun: "scorpio", moon: "cancer", moon_phase: "이지러지는 달",   // 별자리 key · 달 모양 8단계(새달·초승달·상현달·차오르는 달·보름달·이지러지는 달·하현달·그믐달)
  signs: [{ key, korean: "양", symbol: "♈", range: "3.21~4.19", element: "불",
            relation: 합|삼각|육각|사각|충|보통,              // 오늘 달과 그 별자리의 whole-sign 관계 → 격자 색
            score, level, headline, action, caution, lucky_item } ×12]   // 일반판(출생 태양만, 이름 접두 없음)
}
me.horoscope: {                                         // 개인판 — 기본 프로필의 출생 차트 × 오늘 하늘
  chart: { sun: "taurus", moon: "leo",
           asc: "cancer" | null,                        // 저장 시각의 상승 별자리. 시간 미상이면 null
           asc_signs: ["cancer", "leo"],                // 저장된 시(12지시 2시간 블록) 안에서 상승이 지나는 별자리 전부 — 1개면 확실 (2026-11-06)
           uncertain: ["asc"] },                        // 별자리가 확실하지 않은 천체 — 시간 미상이면 그날 바뀌는 sun/moon, 블록 안에서 바뀌면 asc
  score, level, headline, action, caution, lucky_item   // headline은 "{name}님, " 접두 — 일진과 같은 make_brief·레벨 70/40
}
```

## 3. 화면 구성과 순서

카드 하나(`TodayStarsCard`, 홈 `FEED_CARD` 안) — 자리는 **오늘의 띠 바로 아래, 오늘의 타로카드 바로 위**(`specs/home/index.md` §3-1b). 비로그인 홈에도 있다.

1. 제목 "오늘의 별자리" → 회색 소제목 "달이 {♋ 게}자리를 지나요 · {이지러지는 달}"("오늘"은 제목에 있어 소제목엔 안 씀, 2026-11-06)(오늘 태양 별자리 줄 "태양 {♏ 전갈}자리"는 2026-11-06 머리 두 줄 규칙으로 뺌 — `sky.sun`은 API에 그대로)
2. ~~기본 프로필이 있으면 내 출생 차트 칩 3개(☉ 황소 · ☽ 사자 · ↑ 처녀 또는 천칭)~~ — 2026-11-06 홈에서 뺌(사용자 "홈에서 칩은 빼자"). `asc_signs`·`uncertain` 표기 규칙(지나는 별자리를 전부 "또는"으로, 시간 미상이면 상승 없음·바뀌는 천체 `?`)은 `/stars` 내 별자리 세 줄에 그대로(`specs/stars/index.md` §3).
3. 12별자리 격자 6×2(양자리부터, 기호 + `{korean}`) — 칸 색과 오른쪽 위 **등급 라벨**은 **그 별자리의 오늘 점수**(일반판 `signs[].score`, 내 태양 별자리는 개인판 `me.horoscope.score`): 70 이상 금 "최고"(= 좋은 날), 60 이상 초록 "좋음", 42 이하 주황 "주의", 그 사이 흰·라벨 없음(`GradeTag` `gradeOfScore`). 일반판 점수는 90일 표본에서 29~74(중앙값 54)라 레벨 문턱 70/40을 거의 안 넘어 칸 전용 문턱을 둔다 — 하루 평균 좋음 3칸·주의 2~3칸. 2026-11-06 사용자 "평범한 날인데 왜 좋음 라벨이?" — 처음엔 달과의 각도(합·삼각·육각·사각·충)로 색·라벨을 골라 개인 판정과 어긋났다. 달이 머무는 별자리는 소제목에만. 내 태양 별자리 칸 왼쪽 위에 "나" 배지. 격자 아래 범례 줄과 상자 첫 줄의 관계 말(`· 기운 받는 별자리`)은 2026-11-06 뺌(라벨과 겹쳐서; 격자 gap·패딩과 상자 여백도 줄임)
4. 처음엔 내 태양 별자리(없으면 오늘 달의 별자리)가 골라져 있고, 칸을 누르면 상아색 상자에 `{♉ 황소}자리 · 4.20~5.20`(10px, 오른쪽 레벨 배지는 2026-11-06 뺌 — 칸의 등급 라벨이 그 몫) → headline(12px) → `✦ action` → `✕ caution`(11px, 빈 문자열이면 줄 없음) — 굵게 없음(2026-11-06 컴팩트). `행운의 아이템` 줄은 2026-11-06 홈 카드에서 뺌(사용자) — `/stars` 내 별자리·별자리별 오늘에는 그대로
5. **내 태양 별자리 칸이고 기본 프로필이 있으면 `me.horoscope`의 문장**(달·상승까지 넣은 개인판 — 백엔드 "{이름}님, " 접두는 홈 카드에서 `stripName`으로 뗀다, 2026-11-06), 다른 칸은 `today.sky.signs[]`의 일반판(출생 태양만)

## 4. 규칙

**하늘과 차트**
- 서양 점성술 **열대 황도**. 황경은 `ephem`(libastro, `astro_adapter.py`) — ephemeris 파일 없음, 한 번에 1ms 미만, 그날 분점 기준(`epoch=d`). 오늘 하늘은 **오늘 정오 KST**(달은 2.5일마다 궁을 옮긴다).
- 출생 차트는 `profiles.birth_dt`(KST 벽시계 → `ZoneInfo("Asia/Seoul")`로 UTC — 1954~61 +8:30·옛 서머타임은 tzdata가 처리)와 **도시 표 위경도**(`natal_adapter.CITY_LATLON`, 모르는 도시는 서울)로 태양·달·상승점. 프로필에 위도를 저장하지 않는다.
- **시간 미상**(`hour_unknown`): 상승 없음(`asc null`, `asc_signs []`), 태양·달은 정오 저장값, 그날 0시~24시 사이 별자리가 바뀌는 천체는 `uncertain`(칩에 `?`).
- **시간이 있어도 저장값은 12지시 블록의 가운데**(`HOUR_OPTIONS` — 축시 → 02:00, 자시는 전날 23시~01시). 상승은 평균 2시간에 별자리 하나를 지나므로 **블록 시작부터 30분 간격 5점**의 상승 별자리를 모아 `asc_signs`(서울에서 상승은 한 별자리를 최소 75분 지나므로 빠지는 별자리 없음). 2개 이상이면 `uncertain`에 `asc`. 서울 1975~2010 임의 400일 × 12블록 실측: 1개 10.6% · 2개 78.4% · 3개 11.0%(2026-11-05/06) — 즉 한 별자리만 적으면 절반 가까이 틀린다. 점수는 저장 시각의 `asc` 하나로 그대로(달 `uncertain`과 같은 처리 — 상승 가중이 작다).

**애스펙트와 점수**
- **whole-sign 애스펙트** — 별자리 차이로만 본다(0 합 · 4/8 삼각 · 2/10 육각 · 3/9 사각 · 6 충, 1/5/11 보통). 도 단위 오브는 쓰지 않는다 — 정오 추정·2시간 블록에도 결과가 흔들리지 않게.
- 점수 base 50 + 요인표(합/삼각/육각/사각/충 순): 오늘 달→출생 태양 10/12/6/−10/−8 · 달→달 8/8/4/−8/−6 · 달→상승 6/6/3/−6/−4 · 오늘 태양→태양 8/8/4/−8/−6 · 태양→달 4/6/3/−6/−4 · 태양→상승 4/4/2/−4/−3 + 새달(이각 12° 안) +4 · 보름달(168~192°) −3 → 0~100 clamp. 가중치는 전통이 아니라 일진(용신 +25 …)과 같은 척도에 맞춘 우리 값 — 일반판 29~74, 개인판 5~98.
- 레벨은 일진과 같은 `level_fortune`(70/40 → 좋은 날·평범한 날·주의가 필요한 날). 격자 칸 `relation`은 오늘 달→출생 태양의 애스펙트(없으면 보통).

**문장**
- headline·action·caution은 일진의 `make_brief`(가장 큰 요인 하나, 동점이면 흉 우선, 흉이 헤드라인이면 action도 그 요인 것). 요인이 없는 날은 보통 문장 4쌍을 날짜·별자리 순번으로 돌린다.
- 문장 표: (오늘 천체 달·태양 × 출생 자리 태양·달·상승 × 애스펙트 5) 30셀 + 보통 4쌍 + 삭망 2. 행운의 아이템은 내 별자리 원소(불·흙·공기·물)별 6개를 날짜로 회전.
- 달 문장은 "오늘 달이 …", 태양 문장은 "요즘/이 시기 …"("이번 달"은 moon/month가 섞여서 안 씀). 개인판은 "{이름}님, " 접두, 일반판은 접두 없음.

**하지 않는다**
- 외부 기사·운세 API 문장(YTN 별자리 운세는 형식 — 날짜 범위·문단·행운의 아이템 — 만 참고, 페이지에 AI 데이터 활용 금지 고지).
- 접속 위치(ipapi)를 출생지로 쓰지 않는다. 해외 출생의 현지 시간대 보정은 하지 않는다(사주와 같은 KST 벽시계 가정 — v1 한계).
- 외행성(수성~명왕성) 트랜짓·하우스·진행법은 이 카드에 넣지 않는다 — V10 별자리 탭의 몫(`docs/research/astrology_출생차트.md`).
- 별자리 때문에 백엔드 요청을 늘리지 않는다(홈 응답 안).

## 5. 수용 기준

390px 기준.

1. 오늘의 띠 카드 바로 아래에 오늘의 별자리 카드가 있고(비로그인도), 12별자리가 양자리부터 6×2로 있다. 기본 프로필의 태양 별자리 칸에만 "나" 배지가 있고 처음에 그 칸이 골라져 있다(없으면 오늘 달의 별자리). 칸 색은 오늘 달과의 관계(합 금·삼각/육각 초록·사각/충 주황·보통 흰)이고 레벨·점수로 색을 고르지 않는다.
2. 카드 제목은 "오늘의 별자리"이고 소제목 한 줄에 오늘 달의 별자리와 달 모양이 있다(태양 별자리 줄 없음). 격자 칸 오른쪽 위에 등급 라벨(최고·좋음·주의, 보통은 없음)이 있고 내 태양 별자리 칸 왼쪽 위에 "나"가 있다. 칸을 누르면 날짜 범위·한 줄·✦ 행동이 나오고(레벨 배지는 2026-11-06 제거), caution이 빈 칸은 ✕ 줄이 없다. 행운의 아이템 줄은 없다(2026-11-06 제거, `/stars`에만). 격자 아래 범례 줄은 없다(2026-11-06). 내 태양 별자리 칸의 문장은 개인판(`me.horoscope`)이되 이름 접두 없이 시작하고(2026-11-06 — `/stars` 내 별자리는 접두 그대로), 다른 칸은 일반판(`today.sky.signs`)이다.
3. 홈 카드에 출생 차트 칩(☉·☽·↑)은 없다(2026-11-06 제거) — 세 자리는 `/stars` 내 별자리에서 본다.
4. 태어난 시(2시간 블록) 안에서 상승 별자리가 바뀌는 프로필은 `chart.asc_signs`가 둘 이상이고 `/stars` ↑ 줄이 "처녀 또는 천칭"처럼 지나는 별자리를 모두 적는다(2026-11-06 베타: 1989-08-16 08:00 서울). 블록 안에서 안 바뀌면 한 별자리만이다.
