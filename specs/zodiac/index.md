## 1. 목적

홈 카드는 칸을 눌러야 띠 하나씩 보인다. 이 페이지는 **옛 신문의 "띠별 운세" 한 면**처럼 12띠의 오늘을 다 펼치고, 사주까치답게 **이번 주 좋은 날**을 얹는다 — 날마다 바뀌는 일진의 지지와 내 띠가 삼합·육합이면 기운 받는 날, 충·원진이면 조심할 날, 같은 띠면 주인공인 날. 분석의 택시(擇時) 탭이 달 단위라면 여기는 날 단위다. 문장은 전부 백엔드(`zodiac[].advice`), 외부 운세 문장은 쓰지 않는다.

## 2. 진입과 상태

| 상태 | 요청 | 보이는 것 |
|---|---|---|
| 로그인, 기본 프로필 있음 | `GET /kkachi/zodiac/week?member_id=` | 내 띠(오늘 한 줄 + 일진과의 관계) → 이번 주 좋은 날(내 띠 기준) → 띠별 오늘("나" 배지) |
| 로그인, 기본 프로필 없음 | 같은 요청 → `me: null` | 내 띠 카드 대신 "기본 프로필을 정하면 …" 한 줄 → `/profile` |
| 비로그인, `/analysis` 입력값 있음 | `GET /kkachi/zodiac/week?birth_dt&gender[&hour_unknown&city]`(sessionStorage `kkachi_analysis_input`) | 로그인과 같음 |
| 비로그인, 입력값 없음 | 파라미터 없이 | "내 사주를 먼저 보면 …" 한 줄 → `/analysis`, 좋은 날은 오늘의 띠 기준 |

- 로그인 불필요(`/tarot`·`/stars`와 같은 정책). 하단 메뉴에 칸을 더하지 않는다 — 진입은 홈 오늘의 띠 카드 제목 줄 오른쪽 [자세히 →].
- 백엔드 호출은 **한 번**. 이벤트 `zodiac_view{page:"zodiac", logged_in, personal}`.

```
GET /kkachi/zodiac/week  ?days=7(1~14) [&member_id | &birth_dt&gender&hour_unknown&city]   (로그인 불필요)
→ { date,
    today: { date, day_pillar, day_kor, animal{branch,korean,emoji,color}, zodiac[12]{branch,korean,emoji,relation,years[5],advice}, solar_term, son_eomneun_nal },   // = /kkachi/today 에서 sky·tarot 뺀 것
    days: [{ date, day_pillar, day_kor, animal, son_eomneun_nal, solar_term(그날이 절기면 이름|null), zodiac[12]{branch, relation, advice} }] × days,
    me: { branch } | null }   // 내 띠 = 년지(입춘 기준 natal) — 이름·이모지·년생은 today.zodiac에서 찾는다
```
- `member_id`가 있으면 그 회원의 기본 프로필(`is_self`), 없으면 `birth_dt&gender` 직접 입력 — 둘 다 없거나 기본 프로필이 없으면 `me: null`(404 아님). 띠는 `KkachiService.analyze_natal`의 년주 지지라 **입춘 전 출생은 전해 띠**(1990-01-20 → 巳 뱀띠).
- 계산은 `fortune_rules.build_zodiac_week`(순수 함수) — 날마다 `build_today`. 저장 없음.

## 3. 화면 구성과 순서

`PageHeader` 제목 "오늘의 띠", 설명 "{갑신(甲申)} — {푸른 원숭이}의 날". 카드 세 장, 머리는 제목 + 소제목 두 줄까지(홈 카드 규약).

1. **내 띠**(개인판이 있을 때) — 제목 "내 띠" + 오른쪽 등급 라벨(홈 격자와 같은 `GradeTag` — 최고·좋음·주의, 보통은 없음; 2026-11-06 관계 배지에서 바꿈), 소제목 "{🐍 뱀}띠 · 65·77·89·01·13년생" → 상아색 상자: 오늘 내 띠의 한 줄(`advice`) + 작은 글 "오늘 일진 {🐵 원숭이}의 날과 {뱀}띠는 {삼합}이에요"(같은 띠 "같은 띠예요", 보통 "특별한 관계가 없어요"). 개인판이 없으면 같은 제목에 안내 한 줄만(`/profile` 또는 `/analysis`).
2. **이번 주 좋은 날** — 소제목 "{🐍 뱀}띠 기준 · 날마다 일진의 띠와 맺는 합·충으로 봐요". 7칸 가로 띠(오늘·내일·M/D): 그날 일진 띠 이모지 + 일진 이름(갑신) + 칸 오른쪽 위 등급 라벨(기준 띠와의 관계 — 최고·좋음·주의, 보통은 없음; 2026-11-06 관계 점에서 바꿈). 누르면 아래 상자에 "{오늘} · {갑신(甲申)} — {푸른 원숭이}의 날" + 🌿 절기(그날이 절기면)·👻 손없는 날 배지 → 등급 라벨 + "{🐍 뱀}띠에겐 일진 띠와 {삼합}인 날이에요." → `✦` 그날 그 띠의 한 줄. 기준 띠는 내 띠(없으면 오늘의 띠)이고 3번 목록에서 다른 띠를 누르면 바뀐다.
3. **띠별 오늘** — 소제목 "{🐵 원숭이}의 날, 12띠의 하루 — 라벨은 일진 띠와의 관계예요". 子부터 12줄: 이모지(왼쪽 관계 점은 2026-11-06 뺌 — 등급 라벨과 겹쳐서) · "{쥐}띠" · 년생 · (내 띠면 "나") · 오른쪽 등급 라벨 → 한 줄(`advice`). 누르면 그 줄이 상아색으로 고정되고 좋은 날의 기준 띠가 그것으로 바뀌며 오늘 칸으로 돌아간다(펼침 없음 — 한 줄이 전부).
4. 맨 아래 [← 홈으로].

## 4. 규칙

- 문장은 응답 `advice` 그대로(관계별 4문장을 날짜·띠 순번으로 돌리는 것은 백엔드 `build_today`). 프론트는 관계 → 색·이름 표(`RELATION_META`)만 갖는다 — 홈 격자와 같은 색.
- 관계 이름: 삼합·육합 "기운 받는 띠/날", 충·원진 "조심할 띠/날", 같은 띠 "오늘의 주인공/주인공인 날", 보통 "보통/보통인 날". 구체 관계(삼합·충 …)는 상자 문장에 한 번 적는다.
- 하지 않는다: 띠 성격 풀이(분석 십이지신 탭 몫), 두 사람 띠궁합(궁합 탭 몫), 외부 운세 문장, 요청 늘리기(한 번), 하단 메뉴 칸.

## 5. 수용 기준

390px 기준.

1. 홈 오늘의 띠 카드 제목 줄 오른쪽 [자세히 →]를 누르면 `/zodiac`이 열리고, 제목 "오늘의 띠" 아래 설명이 홈 카드 소제목과 같은 "{갑신(甲申)} — {푸른 원숭이}의 날"이다.
2. 로그인(기본 프로필 있음)이면 첫 카드 "내 띠"에 등급 라벨(보통이면 없음)·"{🐍 뱀}띠 · 년생"·오늘 한 줄·일진과의 관계 문장이 있다. 1989-08-16 프로필은 뱀띠, 1990-01-20(입춘 전) 출생은 뱀띠(전해)다.
3. 비로그인·입력값 없음은 "내 띠" 카드가 안내 한 줄("내 사주를 먼저 보면 …" → `/analysis`)이고 좋은 날 기준이 오늘의 띠이며 띠별 오늘에 "나" 배지가 없다.
4. 이번 주 좋은 날은 7칸(오늘·내일·M/D)이고 오늘 칸이 골라져 있다. 칸을 누르면 아래 상자의 날짜·일진·등급 라벨·한 줄이 바뀌고, 그날이 절기·손없는 날이면 배지가 붙는다.
5. 띠별 오늘은 12줄이고 한 줄을 누르면 그 줄이 상아색으로 고정되며 좋은 날 소제목의 기준 띠가 그것으로 바뀐다.
6. 백엔드 테스트(`tests/adapter/test_zodiac_controller.py`, 2026-11-06 통과): 파라미터 없음 → `me null`·7일 연속 날짜·`today`는 `/kkachi/today`에서 sky·tarot를 뺀 것과 같음·날짜 칸 키 7개·`zodiac` 12·"나" 하나 · `member_id` → 기본 프로필 午(친구 未 아님) · 직접 입력 1991-08-20 → 未, 1990-01-20 → 巳(입춘 전) · 없는 회원·성별만 → `me null` · `days=15` 422.
7. 백엔드 호출 1회, 가로 스크롤 없음.
