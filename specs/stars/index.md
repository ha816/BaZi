## 1. 목적

홈 카드는 칸을 눌러야 별자리 하나씩 보인다. 이 페이지는 **옛 신문의 "별자리별 운세" 한 면**처럼 12별자리의 오늘을 다 펼치고, 거기에 사주까치만 줄 수 있는 두 가지를 얹는다 — **내 출생 차트(태양·달·상승)로 본 개인판**과 **이번 주 달의 길**(달이 2~3일마다 별자리를 옮기므로 내 별자리와의 관계가 날마다 바뀐다). 문장·점수는 전부 백엔드, 외부 운세 문장은 쓰지 않는다(`home/horoscope.md` §1 원칙 그대로).

## 2. 진입과 상태

| 상태 | 요청 | 보이는 것 |
|---|---|---|
| 로그인, 기본 프로필 있음 | `GET /horoscope/week?member_id=` | 내 별자리(개인판 오늘 + 출생 차트 세 자리) → 달의 길(내 문장) → 별자리별 오늘("나" 배지) |
| 로그인, 기본 프로필 없음 | 같은 요청 → `me: null` | 내 별자리 카드 대신 "기본 프로필을 정하면 …" 한 줄 → `/profile` |
| 비로그인, `/analysis` 입력값 있음 | `GET /horoscope/week?birth_dt&gender[&hour_unknown&city&name]`(sessionStorage `kkachi_analysis_input`·`kkachi_analysis_name`) | 로그인과 같음(이름 접두는 입력한 이름) |
| 비로그인, 입력값 없음 | 파라미터 없이 | "내 사주를 먼저 보면 …" 한 줄 → `/analysis`, 달의 길은 오늘 달의 별자리 기준 |

- 로그인 불필요(`/tarot`와 같은 정책). 하단 메뉴에 칸을 더하지 않는다 — 진입은 홈 오늘의 별자리 카드 제목 줄 오른쪽 [자세히 →].
- 백엔드 호출은 **한 번**. 이벤트 `stars_view{page:"stars", logged_in, personal}`.

```
GET /horoscope/week  ?days=7(1~14) [&member_id | &birth_dt&gender&hour_unknown&city&name]   (로그인 불필요)
→ { date,
    today: { sun, moon, moon_phase, signs[12]{key, korean, symbol, range, element, relation, score, level, headline, action, caution, lucky_item} },   // 홈 카드 today.sky와 같은 값
    days: [{ date, sun, moon, moon_phase, signs[12]{key, relation, score, level} }] × days,   // 달의 길 — 문장 없이 관계·점수·레벨만
    me: { chart{sun, moon, asc|null, asc_signs[], uncertain[]},
          days: [{ date, moon, moon_phase, relation, score, level, headline("{이름}님, …"), action, caution, lucky_item }] × days } | null }
```
- `member_id`가 있으면 그 회원의 기본 프로필(`is_self`)로 — 없는 회원·기본 프로필 없음은 `me: null`(404 아님). `member_id`가 없을 때만 `birth_dt&gender`를 본다. 성별만·생년월일만은 일반판.
- 계산은 `horoscope_rules.build_week`(순수 함수) — 날마다 `_get_sky`(정오 KST) × `compute_horoscope`. 7일 × 12별자리 + 개인 7일, 전부 1ms 안팎. 저장 없음.

## 3. 화면 구성과 순서

`PageHeader` 제목 "오늘의 별자리", 설명 "달이 {♎ 천칭}자리를 지나요 · {그믐달}". 카드 세 장, 머리는 제목 + 소제목 두 줄까지(홈 카드 규약).

1. **내 별자리**(개인판이 있을 때) — 제목 "내 별자리" + 오른쪽 등급 라벨(홈 격자와 같은 `GradeTag` — 개인판 점수 70/60/42로 최고·좋음·주의, 보통은 없음; 레벨 배지 ✨ 평범한 날은 2026-11-06 뺌), 소제목 "{♌ 사자}자리 · 7.23~8.22" → 상아색 상자: headline("{이름}님, …") → `✦ action` → `✕ caution`(빈 값이면 없음) → "행운의 아이템 · …" → 출생 차트 세 줄(`☉ 태양` 의지와 정체성 / `☽ 달` 감정과 컨디션 / `↑ 상승` 첫인상과 몸) — 값은 별자리 한글 이름, 달이 그날 바뀌면 `?`, 상승은 `asc_signs`를 "처녀 또는 천칭"으로 다 적고 "태어난 시(2시간) 안에서 바뀌어 둘 다 적어요", 시간 미상이면 "출생 시간을 넣으면 보여요". 개인판이 없으면 같은 제목에 안내 한 줄만(`/profile` 또는 `/analysis`).
2. **이번 주 달의 길** — 소제목 "달은 2~3일마다 별자리를 옮겨요 · {♌ 사자}자리 기준". 7칸 가로 띠(날짜 M/D — "오늘·내일" 대신, 2026-11-06 사용자): 달 별자리 기호·이름 + 칸 오른쪽 위 등급 라벨(그날 기준 별자리의 점수 — 내 별자리면 개인판 `me.days[i].score`, 아니면 `days[i].signs[]` — 최고·좋음·주의, 보통은 없음; 2026-11-06 관계 점에서 바꿈). 누르면 아래 상자에 "{11/6(목)} · 달 {♎ 천칭}자리 · {그믐달}" + 레벨 배지(레벨 배지는 이 상자에만 — 2026-11-06) → 기준이 내 별자리이고 개인판이 있으면 그날의 내 headline·✦·✕, 아니면(비로그인이거나 다른 별자리를 골랐을 때) "{♌ 사자}자리에겐 기운 받는 날이에요 — 달과 삼각." 기준 별자리는 내 별자리(없으면 오늘 달의 별자리)이고 3번 목록에서 다른 별자리를 누르면 바뀐다.
3. **별자리별 오늘** — 소제목 "달이 {♎ 천칭}자리에 있을 때 12별자리의 하루 — 색은 오늘 달과의 관계예요". 양자리부터 12줄: 관계 점 · 기호 · "{양}자리" · 날짜 범위 · (내 별자리면 "나") · 오른쪽 등급 라벨(점수 기준, 내 별자리는 개인판) → headline 한 줄(접힘은 1줄 말줄임). 누르면 펼쳐져 ✦·✕·행운의 아이템, 동시에 달의 길 기준이 그 별자리로 바뀌고 오늘 칸으로 돌아간다.
4. 맨 아래 [← 홈으로].

## 4. 규칙

- 문장·점수·레벨은 응답 그대로. 프론트는 레벨·점수로 문장을 고르지 않는다. 관계 → 색 표는 홈 격자와 같다.
- 개인판 문장은 백엔드가 "{이름}님, " 접두를 붙인 것(로그인은 프로필 이름, 비로그인은 입력한 이름, 없으면 접두 없음).
- 출생 차트의 뜻 세 줄(의지·감정·첫인상)은 표시용 상수(`CHART_POINTS`) — 해석 분기가 아니라 용어 설명.
- 달의 길 7일은 **정오 KST** 기준이라 달이 그날 중에 별자리를 옮기면 전후가 다를 수 있다 — 설명 문구에 "2~3일마다"로만 적고 시각은 안 적는다(v1).
- 하지 않는다: 외행성·하우스·진행법(V10 몫), 외부 운세 문장, 별자리 때문에 요청 늘리기(한 번), 하단 메뉴 칸.

## 5. 수용 기준

390px 기준.

1. 홈 오늘의 별자리 카드 제목 줄 오른쪽 [자세히 →]를 누르면 `/stars`가 열리고, 제목 "오늘의 별자리" 아래 설명에 오늘 달의 별자리·달 모양이 있다.
2. 로그인(기본 프로필 있음)이면 첫 카드 "내 별자리"에 "{♌ 사자}자리 · 7.23~8.22"(레벨 배지 없음, 2026-11-06)·"{이름}님, "으로 시작하는 한 줄·✦·행운의 아이템이 있고, 아래 ☉·☽·↑ 세 줄이 있다. 상승이 2시간 블록 안에서 바뀌는 프로필(1989-08-16 08:00 서울)은 ↑ 줄이 "처녀 또는 천칭"이고 그 이유 문구가 있다. 시간 미상 프로필은 ↑ 줄이 "출생 시간을 넣으면 보여요".
3. 비로그인·입력값 없음은 "내 별자리" 카드가 안내 한 줄("내 사주를 먼저 보면 …" → `/analysis`)이고, 달의 길 기준이 오늘 달의 별자리이며, 별자리별 오늘에 "나" 배지가 없다.
4. 이번 주 달의 길은 7칸(날짜 M/D, 2026-11-06 — 오늘·내일 라벨 없음)이고 오늘 칸이 골라져 있다. 칸을 누르면 아래 상자의 날짜(M/D(요일))·달 별자리·레벨 배지가 바뀌고, 기준이 내 별자리면 그날의 내 문장이, 다른 별자리를 골랐으면 그 별자리의 관계 한 줄이 나온다.
5. 별자리별 오늘은 12줄이고 접힌 줄은 한 줄 말줄임이다. 한 줄을 누르면 펼쳐지고(✦·✕·행운의 아이템) 달의 길 소제목의 기준 별자리가 그것으로 바뀐다.
6. 백엔드 테스트(`tests/adapter/test_horoscope_controller.py`·`test_horoscope_rules.py test_build_week_*`, 2026-11-06 통과): 파라미터 없음 → `me null`·7일 연속 날짜·`today.signs` 12·날짜 칸은 {key, relation, score, level}만 · 직접 입력 → `me.chart`(1990-05-03 09:00 `asc_signs ["cancer","leo"]`)·개인 days 이름 접두·시간 미상 `asc null` · `member_id` → 기본 프로필(친구 아님)·없는 회원 `me null`·`days=20` 422·성별만 일반판 · `build_week.today == build_sky`.
7. 백엔드 호출 1회, 가로 스크롤 없음.
