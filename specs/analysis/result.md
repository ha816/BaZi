## 1. 목적

분석 직후 **나의 캐릭터 한 장**으로 "내 얘기네?"를 만들고, 그다음 9개 탭을 끝까지 넘겨 보게 한다. 결과가 백과사전처럼 펼쳐져 첫 탭만 보고 나가던 문제(ROADMAP §1-1)를 인트로 → 설문 → 탭 → 다음 이야기 흐름으로 푼다.

지키는 원칙
- 해석 문장·점수·예측은 전부 백엔드. 프론트의 `lib/ganji.ts`·`tabs/natal/data.ts`는 이름·색·한 줄 태그라인 같은 표시 메타만 — **해석 분기 금지**.
- 카드 포맷은 통일 — 카드 틀 + 제목(필요하면 "상세 설명 ▼" 접힘) + 구분선 + 본문 첫 줄 까치 팁(`{이름}님`으로 개인화) (REFACTORING §4-3). 상세 설명 글은 폰 기준 4줄(390px에서 약 120자) 이내(2026-10-18 규칙, 2026-10-23 분석 카드 전부 적용) — 그림·칸(충합 원 그림 2개, 삼재 3단계 칸, 십신 오분류 칸)은 글자 수에 세지 않고 그대로 둔다.
- 폰 한 화면 기준. 깊은 내용은 "확인하기"로 열어 한 번에 다 펼치지 않는다.
- 여기서 만든 장치는 궁합 결과에도 같은 모양으로 넣는다(V6).

## 2. 진입과 상태

- **로그인 불필요.** 직접 입력은 비로그인도 결과까지 본다. 프로필 모드만 로그인.
- 결과는 **폼을 대체**한다. 페이지 헤더 오른쪽에 [공유] [다시 입력]. 다시 입력은 결과를 지우고 주소를 `/analysis`로 되돌리되 sessionStorage는 남긴다(재진입하면 자동 분석).
- 프로필 결과이고 그 프로필에 저장된 다른 연도가 있으면 헤더 아래 "지난 연도 다시 보기" 칩 + "{연도}년 보는 중" 표시. 칩을 누르면 그 연도의 캐시 결과(R6).
- **재진입**: sessionStorage에 `kkachi_analysis_input`이 있으면 자동으로 다시 분석해 결과를 바로 띄운다. 주소에 `step`·`tab`이 없으니 인트로부터 다시.
- **단계 `?step=`**
  - 새 결과(주소에 `step`·`tab`이 없음)이고 `natal.character`가 있으면 `intro`부터. 주소에 `?step=intro`를 남긴다(replaceState). 캐릭터가 없는 옛 결과는 인트로 없이 대시보드.
  - 인트로 → 설문은 `?step=survey`로 pushState. 폰 뒤로 가기로 인트로로 돌아온다. `?step=survey`는 `self_quiz`가 있을 때만 유효.
  - 인트로·설문의 "내 사주 분석 보기"는 `?tab=natal`로 pushState 하고 맨 위로.
  - `?tab=`이 있는 주소를 새로고침하면 인트로 없이 그 탭.
  - 인트로·설문이 덮는 동안 뒤 화면은 스크롤되지 않고 탭 본문은 마운트하지 않는다(닫힌 뒤 팔자 등장 연출이 사용자 눈앞에서 돌게).
- **탭 `?tab=`** 은 replaceState로만(서버 왕복 없음). 기본 `natal`. 옛 `summary`는 `natal`로(한눈에 탭은 2026-10-13 제거). `self_quiz`가 없는 옛 결과는 설문조사 탭을 숨긴다(8탭).
- **설문 상태**(답·제출)는 오케스트레이터가 들고 인트로 설문과 설문조사 탭이 같이 쓴다. 서버에 보내지 않는다. 결과가 사라지면 함께 초기화.
- **이벤트**: `result_view{has_profile}` · `tab_view{tab, has_profile}` · `timing_view{domain}` · `share_click{channel}`. 새 이벤트는 추가하지 않는다(2026-09-28). `summary_view`는 더 이상 나가지 않는다.
- **출생시간 미상**(`natal.hour_unknown`): 탭바 위에 "⚠️ 출생시간을 몰라 연주, 월주, 일주로만 분석했어요. 시간을 알게 되면 다시 입력해 보세요." 고지. 사주팔자의 시주 자리는 "?" 타일, 만세력 섹션은 3열(R2).

## 3. 화면 구성과 순서

### 3-1. 인트로 (`?step=intro`, 전체 화면)

1. 머리줄 "✓ 분석 완료" + 오른쪽 [건너뛰기] (펼치는 중에는 숨김)
2. **두근두근 게이트** — "두근두근 🐦 / ○○님의 캐릭터는?" + 캐릭터 실루엣(그림을 미리 받아 두고 "?"를 겹침) + [🎁 내 캐릭터 확인하기]
3. 누르면 10천간 슬롯(이모지 · 한자 · 한글)이 약 1.9초 동안 점점 느려지며 돌다 **내 일간**에서 멈춘다("일간을 찾는 중…" → "짠! ✨"). 약 0.5초 뒤 공개
4. **공개 화면** — 캐릭터 그림(`saju_character/{key}.webp`, 없으면 기본 까치) → "○○님의 캐릭터" → 유형명 → 한 줄 → 까치 인사 말풍선 "반갑습니다. ○○님! {연도}년 기준으로 사주를 풀어드릴게요." + 설문이 있으면 "아래 설문조사를 하면 이 풀이가 나와 얼마나 맞는지 알려드려요. (바로 분석으로 가도 되구요)"
5. 아래 고정 버튼 — [📋 설문조사](설문 있을 때) / [🗺️ 내 사주 분석 보기]
6. 분석 보기 → 나무·불·흙·쇠·물 글자가 차례로 맥동하며 "○○님의 기운에 맞춘 운세 지도를 펼치는 중…" 1.3초 → 만세력 탭

### 3-2. 설문 (`?step=survey`, 전체 화면)

1. 머리줄 "📋 설문조사" + 오른쪽 [분석 바로 보기 ›](제출 전만)
2. **설문조사 카드** — 머리 오른쪽 "k/2 페이지 · n/10 답함", 까치 팁("평소의 ○○님에 가장 가까운 답을 골라 주세요. 10문항을 다 고르면 …"), 문항 블록(Q번호 + 행동 문장, [그렇다 / 아니다] 2칸), 아래 [다음 문항으로 (6~10번) ›] 또는 마지막 페이지에선 [🔮 사주 예측과 맞춰 보기], 2페이지엔 "‹ 이전 문항 (1~5번)" 링크
3. 제출 뒤 — "답변 완료!" + "사주와 얼마나 맞는지는 📋 설문조사 탭에 숨겨 뒀어요. 분석을 먼저 보고 확인해 보세요." + 아래 고정 [🗺️ 내 사주 분석 보기]. **일치율은 여기서 보여주지 않는다.**

### 3-3. 탭바

고정 상단, 한 줄 6개라 9탭은 6+3 두 줄(설문 없는 옛 결과는 8탭). 순서·라벨·"다음 이야기" 제목:

| # | `?tab=` | 라벨 | 다음 이야기 제목(hook) | 노출 조건 |
|---|---|---|---|---|
| 1 | `natal` | 🌱 만세력 | 내 여덟 글자에 담긴 성향은? | 항상(기본) |
| 2 | `energy` | ⭐ 신살·운성 | 나에게 붙은 귀인과 신살은? | 항상 |
| 3 | `yongshin` | 🔮 용신·삼재 | 나를 돕는 오행은 무엇일까? | 항상 |
| 4 | `timing` | 🗓️ 택시(擇時) | 올해 언제 움직이면 좋을까? | 항상 |
| 5 | `daeun` | 🌊 시운(時運) | 10년·올해·이번 달의 흐름은? | 항상 |
| 6 | `zodiac` | 🐾 십이지신 | 띠로 보는 나와 올해는? | 항상 |

- 우하단 **까치 상담 FAB** → `/chat` (결과가 있을 때만).

## 4. 규칙

**한다**
- 카드는 통일 포맷(카드 틀 + 제목 + 구분선 + 첫 줄 까치 팁 `{이름}님`). 새 카드도 같은 틀.
- 깊은 내용(일간 심상·신강·신약·나의 캐릭터·용신·기신·삼재·연도별 띠 궁합)은 **"확인하기" 게이트** 뒤에 둔다 — 한 번에 다 펼치지 않는다.
- 등장 연출(팔자 도장, 캐릭터 공개)은 **사용자가 보고 있을 때** 돈다 — 인트로·설문이 덮여 있는 동안 탭 본문을 마운트하지 않는다.
- 출생시간 미상은 세 기둥 그대로 보여주고 고지한다(R2). 시간을 추정·보정하지 않는다.
- 옛 결과(캐릭터·설문 없음, `summary` 탭 링크)도 깨지지 않게 — 인트로 생략, 탭 숨김, 첫 탭으로.
- 여기서 만든 장치는 궁합 결과에도 같은 모양으로 넣는다(V6).
- AI 풀이는 **결과가 뜨자마자 미리 시작**하고 상태를 페이지가 들고 있는다(궁합 AI 해석과 같은 구조, 2026-10-23). 같은 입력·이름의 글은 다시 만들지 않는다 — 직접 입력은 sessionStorage(`kkachi_ai_report`), 프로필은 서버 연도 캐시(`analyses.ai_report`), 서버는 같은 입력의 동시 요청에 한 생성을 나눠 준다.
- AI 풀이 글의 분량·섹션·용어 규칙은 프롬프트(`report_builder.py` "쓰는 법")가 정하고, 바뀌면 `REPORT_PROMPT_VERSION`을 올려 옛 글을 버린다. 괄호 밖에 남은 한자(간지·오행·십신·합충)는 서버가 "한글(漢字)"로 바꿔 보낸다.
- 스트림 응답에는 `Cache-Control: no-cache, no-transform`을 붙이고, 로컬 dev의 `/api` rewrite 프록시 대기 상한은 300초(`next.config.ts` `experimental.proxyTimeout`)로 둔다 — 기본 30초는 첫 글자(로컬 32B 29~31초)와 겹쳐 500이 났고, 프록시가 본문을 끝까지 모아 보냈다(2026-10-23).

**하지 않는다**
- 설문으로 **출생시간을 역산하거나 시주 후보를 추천하지 않는다**(사용자 결정 2026-10-03).
- 인트로 설문 제출 직후 화면에서 **일치율을 보여주지 않는다**(2026-10-13) — 분석을 읽기 전에 김새지 않게, 설문조사 탭까지 넘기게.
- 설문 답을 **서버에 보내지 않는다**(저장 여부 미정). 공유 카드에 일치율을 넣지 않는다(ROADMAP V3 메모).
- 프론트에서 **해석을 분기하지 않는다**. 표시 메타(이름·색·태그라인)까지만.
- 한눈에 탭을 다시 만들지 않는다. `postnatal.summary`는 LLM 기본 요약용 API로만(2026-10-13) — AI 풀이 탭의 **대기 화면**에서만 10줄을 보여 준다(2026-10-23, 글이 오면 사라짐).
- AI 풀이 탭을 열 때마다 다시 생성하지 않는다(2026-10-23 이전의 동작).
- 새 행동 이벤트를 추가하지 않는다(2026-09-28).
- 첫 화면(홈 퀵스타트 "30초 만에 내 사주") 앞에 단계를 두지 않는다 — 설문·캐릭터는 모두 **결과 뒤**.

## 5. 수용 기준

인트로
1. 캐릭터가 있는 새 결과를 받으면 주소가 `?step=intro`가 되고 "두근두근 🐦" 화면이 뜬다. [건너뛰기]를 누르면 `?tab=natal` 만세력 탭이다. 캐릭터가 없는 옛 결과는 인트로 없이 만세력 탭이 바로 보인다.
2. [🎁 내 캐릭터 확인하기] → 10천간 슬롯이 돌다 내 일간(예: ⛰️ 戊 무토)에서 멈추고, 약 0.5초 뒤 그림·유형명·한 줄·까치 인사가 보인다. 설문이 있으면 버튼이 둘, 없으면 [🗺️ 내 사주 분석 보기] 하나다.
3. 설문 화면에서 브라우저 뒤로 가기를 하면 슬롯 없이 인트로의 인사 화면으로 돌아온다.
4. `?tab=daeun` 같은 주소를 새로고침하면 인트로 없이 그 탭이 바로 보인다.

설문
5. 10문항이 5+5 두 페이지로 나뉘고 머리에 "1/2 페이지 · 0/10 답함"이 보인다. 첫 페이지에는 Q1~Q5만 있다.
6. 1페이지 5문항을 다 고르기 전에는 아래 버튼이 비활성이고 "이 페이지에 m개 남았어요"다. 다 고르면 "다음 문항으로 (6~10번) ›"로 바뀌고 눌린다.
7. 다음을 누르면 Q6이 보이고 화면이 카드 머리로 올라간다(전체 화면에서는 스크롤 0, 탭에서는 2줄 고정 탭바 아래). "‹ 이전 문항 (1~5번)"으로 돌아가도 고른 답이 그대로다.
8. 2페이지에서 전부 답하면 [🔮 사주 예측과 맞춰 보기]가 활성. 인트로 흐름에서 누르면 "답변 완료!"만 보이고 일치율은 없다. 설문조사 탭에서 보면 "사주와 설문 응답의 일치율" %·까치 해설·문항별(다른 문항 먼저, 근거는 다른 문항에만)이 보인다.
9. 인트로에서 1페이지만 답하고 [분석 바로 보기 ›]로 나간 뒤 설문조사 탭을 열면 2페이지부터 보인다. [다시 답하기]를 누르면 1페이지로 돌아가고 답이 모두 지워진다.

탭
10. 탭은 9개(6+3 두 줄), 기본은 만세력. `self_quiz`가 없는 옛 결과는 설문조사 탭이 없다. 옛 `?tab=summary` 링크는 만세력 탭이다.
11. 만세력 탭의 카드 순서는 사주팔자 → 신강·신약 → 나의 캐릭터 → 십신 → 지장간 → 공망(있을 때)이다.
12. 만세력 탭이 열릴 때 팔자 기둥이 시→일→월→년 순으로 솟고 글자가 도장처럼 찍힌다. 인트로·설문이 덮여 있는 동안에는 재생되지 않는다.
13. 일간 심상·신강·신약·나의 캐릭터·용신·기신·삼재·연도별 띠 궁합은 "확인하기" 버튼을 눌러야 열린다(일간 심상만 한 번 열면 기억). 나의 캐릭터를 열면 그림 → 유형명·한 줄 → 선호하는 일 \| 선호하지 않는 일 칩 → 기운 % 게이지 순이고, 자연물 비유 이름은 보이지 않는다.
14. 탭을 바꾸면 주소의 `tab`만 바뀌고 전체 새로고침이 일어나지 않는다. 아래로 내려 읽던 중이었다면 새 탭 첫 줄이 탭바 바로 아래로 올라온다.
15. 모든 탭 끝에 다음 이야기 카드가 있고 제목은 3-3 표의 hook과 같다. AI 풀이 탭의 다음은 만세력이다. 설문을 제출한 뒤에는 설문조사 탭의 hook이 "답해 둔 설문, 내 사주와 몇 % 맞았을까?"다.
16. 다음 이야기 아래 "이 해석이 도움이 됐나요?" 👍/👎가 있고 누르면 "감사합니다!"로 바뀐다. 프로필 결과만 서버에 보내고, 직접 입력 결과는 버튼만 보인다. 다른 탭으로 가면 다시 물어본다.
17. 출생시간 미상 결과는 탭바 위에 ⚠️ 고지가 있고, 사주팔자의 시주 자리가 "?" 타일이며, 만세력 섹션은 3열이다.
18. 택시 탭에서 달을 고르면 그 달의 근거·행동이 보이고 `timing_view{domain}` 이벤트가 나간다.

헤더·공유
19. 결과 헤더의 [공유]는 `/s/{id}` 링크를 만들고, 미리보기 제목·문구는 캐릭터가 있으면 "○○님은 {유형명}"이다. [다시 입력]은 폼으로 돌아가고 주소가 `/analysis`가 되며, 다시 들어오면 자동 분석된다.
20. 프로필 결과에 저장된 다른 연도가 있으면 "지난 연도 다시 보기" 칩이 보이고, 누르면 그 연도 결과가 뜨며 "{연도}년 보는 중"이 바뀐다.
21. 까치 상담 FAB는 결과가 있을 때만 보이고, 누르면 `/chat`이다.

AI 풀이
22. 결과가 뜨면 AI 풀이 탭을 열기 전에 스트림 요청이 한 번 나간다. 다른 탭에 갔다 돌아와도 글이 그대로 있고 요청은 여전히 한 번이다.
23. 글이 오기 전 AI 풀이 탭에는 "까치가 사주를 풀어내고 있어요… 보통 1~2분 걸려요"와 "글이 오는 동안 먼저 보는 요약"(나·신살·운성·용신·삼재·택시·올해·이번 달·오늘·조심·십이지신·풍수)이 보이고, 첫 글자가 오면 요약은 사라진다.
24. 글은 나는 어떤 사람 → 지금 흐름 → 영역별 전략 → 앞으로 열두 달 → 개운 한 가지 다섯 섹션 제목과 마지막 **한 줄 총평** 한 줄이다. 괄호 밖에 한자가 없고 표가 없다.
25. 까치 서버(Ollama)가 꺼져 있으면 "AI 풀이는 까치 서버(Ollama)가 켜져 있을 때 제공돼요. 다른 탭의 풀이는 그대로 볼 수 있어요."와 [다시 시도]가 보이고, 누르면 요청이 다시 나간다.
26. 새로고침해도 같은 입력·이름이면 직접 입력 결과의 글이 요청 없이 바로 보인다. 프로필 결과는 다른 날 다시 열어도 글이 바로 보인다(연도 캐시에 저장).
